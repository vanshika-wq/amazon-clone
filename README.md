# 🛒 Amazon Clone — Full Stack E-Commerce Web App

A fully functional **Amazon Clone** built using modern full-stack technologies.  
It supports product listing, authentication, cart system, and backend API integration.

---

## 🌐 Live Demo
👉 https://amazon-clone-ruddy-six.vercel.app

---

## ⚙️ Tech Stack

### 🖥️ Frontend
- React 18 (Vite)
- Tailwind CSS
- Redux Toolkit (State Management)
- Axios

### 🧠 Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- bcrypt

### ☁️ Deployment
- Frontend → Vercel
- Backend → Render
- Database → MongoDB Atlas
